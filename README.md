# Velvet Salon

A single-page website for Velvet Salon, a hair salon on Pearl Street in Brooklyn. The page covers the service menu, stylist profiles, shop story, photo gallery, reviews, questions, and hours.

Open `index.html` in a browser. No install or build step is required.

## Contact

- Email: book@velvetsalon.com
- Hours: Monday closed; Tuesday–Friday 9:00 AM–7:00 PM; Saturday 9:00 AM–6:00 PM; Sunday 10:00 AM–4:00 PM

## Sections

- Announcement bar with hours, address, and phone
- Hero and shop stats
- Service menu and prices
- Stylist profiles
- Shop story
- Photo gallery
- Reviews
- FAQ accordion
- Hours, location, and booking
- Footer with the same contact details

## Files

- `index.html` — page content
- `styles.css` — layout and styling
- `script.js` — mobile menu and FAQ behavior
